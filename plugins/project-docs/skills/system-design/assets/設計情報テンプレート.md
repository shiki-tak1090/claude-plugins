**書き方のルール**

- 決まっていないことは【要確認】と書き、確認する相手を添える
- 作成者が仮に置いた前提は【仮定】と書き、確かめる時期を添える。仮定のまま設計書に決定事項として書かない
- 要件定義書に書かれていることは、要件 ID で参照し、書き写さない
