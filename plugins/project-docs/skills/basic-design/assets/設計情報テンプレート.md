**この文書は社内向けであり、納品物ではない。** 基本設計と詳細設計は、この文書を前提に書く。ここに書かれていないことを、設計書の作成者（AI を含む）が一般論で補わない。

**書き方のルール**

- 決まっていないことは、未決定事項一覧に行を足し、ここでは【未決定】と書く
- 作成者が仮に置いた前提は【仮定】と書き、確かめる時期を添える。仮定のまま設計書に決定事項として書かない
- 要件定義書に書かれていることは、要件 ID で参照し、書き写さない
